# WID-SEC-2026-0117: Microsoft Exchange - Schwachstelle ermoeglicht Offenlegung von Informationen

CVSS Base: 5.3 | Classification: mittel
CVEs: CVE-2026-10117
Affected products: Exchange Server 2019 CU14, Exchange Server 2016 CU23
Published: 2026-07-23
Update: Weiterer betroffener Kumulativer Update-Stand ergaenzt.

## Produktbeschreibung
Microsoft Exchange Server ist eine E-Mail- und Kalenderplattform, die in Unternehmensnetzwerken haeufig zentrale Kommunikationsdienste bereitstellt.

## Angriffsbeschreibung
Ein entfernter Angreifer kann durch das Senden praeparierter Anfragen an Microsoft Exchange auf Informationen zugreifen, auf die er eigentlich keinen Zugriff haben sollte. Betroffen sind unter anderem interne Konfigurationsdaten und Session-Informationen. Update vom 2026-07-23: Weiterer betroffener Kumulativer Update-Stand ergaenzt.
