# WID-SEC-2026-0108: VMware ESXi - Schwachstelle ermoeglicht Rechteausweitung

CVSS Base: 7.8 | Classification: hoch
CVEs: CVE-2026-10108
Affected products: ESXi 8.0.x, ESXi 7.0.x
Published: 2026-07-13

## Produktbeschreibung
VMware ESXi ist ein bare-metal-Hypervisor zur Virtualisierung von Serverinfrastruktur und wird in vielen Rechenzentren als Basis fuer virtuelle Maschinen eingesetzt.

## Angriffsbeschreibung
Ein lokaler, niedrig privilegierter Angreifer kann eine Schwachstelle in VMware ESXi ausnutzen, um seine Rechte auf dem betroffenen System auszuweiten. Ursache ist eine fehlerhafte Berechtigungspruefung in einer internen Komponente.

## Betroffene Produkte
- ESXi 8.0.x
- ESXi 7.0.x
