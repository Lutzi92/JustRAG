# WID-SEC-2026-0119: Atlassian Confluence - Schwachstelle ermoeglicht Ausfuehrung beliebigen Codes

CVSS Base: 9.8 | Classification: kritisch
CVEs: CVE-2026-10119
Affected products: Confluence Data Center 9.2.x, Confluence Server 9.2.x
Published: 2026-07-18

## Produktbeschreibung
Atlassian Confluence ist eine webbasierte Kollaborations- und Wissensmanagement-Plattform, die in vielen Organisationen zur internen Dokumentation eingesetzt wird.

## Angriffsbeschreibung
Ein entfernter, nicht authentisierter Angreifer kann durch das Senden speziell praeparierter Anfragen an Atlassian Confluence beliebigen Code mit den Rechten des betroffenen Dienstes ausfuehren. Die Schwachstelle beruht auf einer unzureichenden Eingabevalidierung.

## Betroffene Produkte
- Confluence Data Center 9.2.x
- Confluence Server 9.2.x
