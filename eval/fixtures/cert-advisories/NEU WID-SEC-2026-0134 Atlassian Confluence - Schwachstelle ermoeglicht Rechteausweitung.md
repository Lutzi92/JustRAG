# WID-SEC-2026-0134: Atlassian Confluence - Schwachstelle ermoeglicht Rechteausweitung

CVSS Base: 7.8 | Classification: hoch
CVEs: CVE-2026-10134
Affected products: Confluence Server 8.5.x
Published: 2026-06-28

## Produktbeschreibung
Atlassian Confluence ist eine webbasierte Kollaborations- und Wissensmanagement-Plattform, die in vielen Organisationen zur internen Dokumentation eingesetzt wird.

## Angriffsbeschreibung
Ein lokaler, niedrig privilegierter Angreifer kann eine Schwachstelle in Atlassian Confluence ausnutzen, um seine Rechte auf dem betroffenen System auszuweiten. Ursache ist eine fehlerhafte Berechtigungspruefung in einer internen Komponente.

## Betroffene Produkte
- Confluence Server 8.5.x
