# WID-SEC-2026-0106: Ivanti Connect Secure - Schwachstelle ermoeglicht Umgehung von Sicherheitsvorkehrungen

CVSS Base: 8.1 | Classification: hoch
CVEs: CVE-2026-10106
Affected products: Connect Secure 22.7.x
Published: 2026-08-31

## Produktbeschreibung
Ivanti Connect Secure (vormals Pulse Connect Secure) ist eine SSL-VPN-Loesung, die Fernzugriff auf Unternehmensnetzwerke absichert.

## Angriffsbeschreibung
Ein entfernter Angreifer kann eine Schwachstelle in Ivanti Connect Secure ausnutzen, um bestehende Sicherheitsvorkehrungen wie Authentifizierung oder Zugriffskontrollen zu umgehen.
