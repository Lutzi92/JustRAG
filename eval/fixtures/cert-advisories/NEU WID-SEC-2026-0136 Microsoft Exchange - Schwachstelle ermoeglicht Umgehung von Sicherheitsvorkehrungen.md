# WID-SEC-2026-0136: Microsoft Exchange - Schwachstelle ermoeglicht Umgehung von Sicherheitsvorkehrungen

CVSS Base: 8.1 | Classification: hoch
CVEs: CVE-2026-10136
Affected products: Exchange Server 2013 CU23
Published: 2026-06-03

## Produktbeschreibung
Microsoft Exchange Server ist eine E-Mail- und Kalenderplattform, die in Unternehmensnetzwerken haeufig zentrale Kommunikationsdienste bereitstellt.

## Angriffsbeschreibung
Ein entfernter Angreifer kann eine Schwachstelle in Microsoft Exchange ausnutzen, um bestehende Sicherheitsvorkehrungen wie Authentifizierung oder Zugriffskontrollen zu umgehen.
